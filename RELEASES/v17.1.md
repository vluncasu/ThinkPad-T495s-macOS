# ThinkPad T495s Hackintosh v17.1 - macOS Ventura | AMD Ryzen + Radeon Vega 10 OpenCore EFI

Tag: `v17.1`

Recommended GitHub state: **Pre-release**

This release freezes the current Lenovo ThinkPad T495s (20QK) Hackintosh state as a reproducible public engineering snapshot. AMD Ryzen 7 PRO 3700U with Radeon Vega 10 (Picasso) GPU acceleration working via NootedRed on macOS Ventura 13.7.8. It documents both working subsystems and unresolved blockers. It does not claim universal T495s compatibility.

## Working or operational paths

The repository distinguishes configuration from observed end-to-end behavior. See `Docs/STATUS.md` and `Docs/TEST-MATRIX.md` for the evidence class attached to every subsystem.

Operational paths include boot through OpenCore, AMD CPU compatibility, internal display output, NootedRed-backed Metal execution, audio, the production Elan PS/2 touchpad path, installer/post-install tooling, and user-space brightness extension infrastructure. Some components are configured but intentionally not promoted to fully validated status where sustained evidence is absent.

## Primary unresolved issue 1 - accelerated graphics stability

Vega 10 framebuffer output and Metal execute through NootedRed. Completed Metal benchmarks are included. However, accelerated Chromium/Chrome workloads have produced AMD GFX-channel hangs and complete system unresponsiveness. Chrome with hardware acceleration disabled is the current containment path. This is a workaround, not a driver fix.

Included benchmark evidence:

```text
Cinebench R23 multi-core: 3141
Geekbench Metal: 11179
Geekbench Metal: 5164
Geekbench CPU: no standalone result supplied
```

## Primary unresolved issue 2 - native sleep/resume

The machine can enter sleep and evidence exists for some wake transitions, but repeatable native suspend/resume and normal lid-close/open behavior are not established. Historical lid-continuity tooling prevents suspend and must not be interpreted as native sleep.

## Brightness architecture

The repository documents three separate layers:

1. macOS brightness control plane and key events;
2. physical backlight response, which exposes only a limited useful hardware range on this panel/path;
3. the v17 AppKit visual overlay, used to extend perceived brightness below the useful physical range without continuously rewriting the display gamma table.

The rejected v15/v16 gamma bridge and its freeze regression are preserved in the development history.

## Touchpad

The production path is Elan PS/2 through VoodooPS2. Conflicting VoodooI2C/VoodooPS2Mouse paths were removed or disabled. Repository documentation records the exact plugin and tuning choices.

## Touchscreen

The touchscreen is identified under Windows as `USB2IIC_CTP_CONTROL`, VID `1A86`, PID `E5E3`. macOS probing has not established normal IOUSB/IOHID enumeration of the target. The bridge under `Experimental/Touchscreen/` is therefore research-only and is not installed by default.

## Wi-Fi during installation

Intel AX200 Wi-Fi is part of the post-install configuration, but AirportItlwm can be unavailable or destabilize the macOS installer environment on this target. The repository includes a dedicated installer profile with AirportItlwm disabled:

```text
EFI/OC/Config-Profiles/config-install-no-wifi.plist
```

The validator checks that this profile differs from the normal public profile only in the intended AirportItlwm enable state.

## Pre-boot compatibility layer

The original Windows-oriented Lenovo ACPI firmware is mediated through OpenCore ACPI patches, including `_OSI -> XOSI` and `SSDT-XOSI`. The repository calls this a pre-boot compatibility layer. It emulates selected operating-system interface responses expected by the firmware; it does not emulate the Windows operating system.

## Public release safety

Real production SMBIOS values are not included. The public configuration contains placeholders for serial, MLB, SystemUUID and ROM. Every user must generate unique production values before normal use.

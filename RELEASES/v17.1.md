# ThinkPad T495s Hackintosh v17.1 - macOS Ventura | AMD Ryzen + Radeon Vega 10 OpenCore EFI

## Download and install macOS on your ThinkPad T495s

### What you get

| File | What it is |
|---|---|
| **ThinkPad-T495s-EFI-v17.1.zip** | OpenCore EFI — makes the laptop boot macOS |
| **ThinkPad-T495s-PostInstall-v17.1.zip** | Scripts — trackpad fix, brightness fix, sleep fix, Chrome fix |

### How to install (short version)

```
1. Make a macOS Ventura USB installer
2. Copy EFI/ folder to the USB's EFI partition
3. Boot from USB (F12 at startup)
4. Install macOS
5. Run Tools/Transfer-EFI.command → copies EFI to internal disk
6. Remove USB — laptop now boots macOS on its own
7. Run Tools/Install.command → trackpad + brightness fix
8. Run Tools/Power/Enable-Continuity.command → sleep fix
9. Generate your own SMBIOS (MacBookPro16,3) for iCloud/iMessage
```

### What works after install

- macOS Ventura 13.7.8
- AMD Ryzen 7 PRO 3700U (all 4 cores / 8 threads)
- Radeon Vega 10 GPU with Metal acceleration (Geekbench Metal: 11179)
- Display 1080p, keyboard, trackpad, Wi-Fi, Bluetooth, USB, NVMe, battery

### Known issues

- **Chrome** — disable hardware acceleration or it freezes the system. Use `Tools/Chrome/Launch-Safe.command`
- **Sleep** — real S3 sleep doesn't work (GPU can't restore state). Use lid-close pseudo-sleep instead
- **Brightness** — only ~2 physical hardware levels. Software overlay fixes this visually
- **Touchscreen** — not detected by macOS

### Important

You MUST generate your own SMBIOS serial numbers with [GenSMBIOS](https://github.com/corpnewt/GenSMBIOS) (model: MacBookPro16,3). Without this, iCloud, iMessage, FaceTime, and App Store will NOT work.

Full documentation: see the [README](https://github.com/vluncasu/ThinkPad-T495s-macOS) and `Docs/` folder.
